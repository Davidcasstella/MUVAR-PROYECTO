# Changelog - MUVAR Frontend

Todos los cambios notables de este proyecto se documentarán en este archivo.

## [1.0.0] - 2026-02-02

### Agregado
- 🏗️ Estructura enterprise completa con Angular 19+
- ✅ Standalone Components
- 🔄 Signals para reactividad
- 🎨 Sistema SCSS con diseño atómico
- 🌐 Sistema de rutas con lazy loading
- 🛡️ Guardias de autenticación y autorización
- 🔌 Interceptores HTTP (autenticación, cabeceras, errores, carga)
- 📁 Barrel exports para imports limpios
- 🎯 Layouts (público y administración)
- 🔐 Sistema de autenticación (acceso, registro, recuperación de password)
- 📊 Dashboard con estadísticas
- 👥 Módulo de usuarios
- 🌍 Soporte multi-idioma (español, inglés)
- 🎨 Sistema de temas (claro/oscuro)
- 📝 Utilidades, constantes y validadores
- ⚙️ Configuraciones de entorno (desarrollo, pruebas, preproducción, producción)

### Configuración
- ESLint + Prettier para código limpio
- TypeScript con modo estricto
- Paths aliases (@nucleo, @compartido, etc.)
- Pre-commit hooks con Husky
